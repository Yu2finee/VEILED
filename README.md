# The Veiled Grimoire

A browser-based learning and journaling site for Wicca, modern witchcraft, folklore, symbolism, tarot study, herbs, protective practices, sigil design, and personal reflection.

## Entrance word

`LUMEN`

The word gate is for atmosphere only. It is not real authentication and should not be used to protect sensitive information.

## Included in Version 1

- Animated **LUMEN** entrance screen
- Learning paths for Wicca, witchcraft, ethics, correspondences, protection, sigils, divination, seasonal practice, and source literacy
- Searchable **Herbarium** with historical/folkloric associations and safety notes
- Large **Protection Library** focused on low-risk practices such as grounding, boundaries, visualization, sound, journaling, and ordinary safety
- Interactive **Sigil Workshop** with symmetry, complexity, randomization, and Book of Shadows saving
- **Wheel of the Year** explorer with all eight commonly observed sabbats
- **Tarot Study Room** with reflective card prompts
- Searchable witchcraft/Wicca **Glossary**
- Local **Book of Shadows** using browser `localStorage`
- Notes export to `.txt`
- Beginner **Study Quiz**
- Approximate moon-phase display
- Random-page button and daily grimoire prompts
- Responsive desktop/mobile layout

## Safety / educational approach

The site distinguishes spiritual or folkloric associations from medical or scientific claims. It does not recommend ingesting, burning, applying, or otherwise using unfamiliar herbs without first checking reliable safety information. Fire, smoke, incense, and essential oils are optional and are not required for any practice on the site.

Tarot and divination are presented as spiritual or reflective tools rather than scientifically reliable future prediction. Protective practices are intended to complement, not replace, real-world safety, healthcare, emergency services, or professional advice.

## Vercel

This is a static site and can be deployed directly from this repository.

1. Import `Yu2finee/VEILED` into Vercel.
2. Framework Preset: **Other**.
3. Root Directory: `./`.
4. Leave Build Command blank.
5. Leave Output Directory blank.
6. Deploy.

## Files

- `index.html` — page structure
- `style.css` — visual design and responsive layout
- `data.js` — educational entries and site content
- `script.js` — navigation, search, sigil generator, notes, quiz, moon phase, and interactions

## Privacy

The Book of Shadows is saved only in the current browser's local storage. It is not encrypted cloud storage and does not sync across devices.
